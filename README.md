# HTTP-Headers-Scanner
A Python-based tool for scanning HTTP security headers.
## HTTP Headers Scanner
A beginner-friendly Python cybersecurity tool that checks a website's HTTP response for important security headers.
## Features
-Checks HTTP response headers
-Detects missing security headers
-Displays the HTTP status code
-Provides a short explanation for missing headers
-Built with Python and Requests
## Security Headers Checked
-Content-Security-Policy
-Strict-Transport-Security
-X-Content-Type-Options
-X-Frame-Options
-Referrer-Policy
-Permissions-Policy
## Requirements
-Python 3
-Requests
Install the required library:
pip install requests
